CVE-2026-73445 gRPC gRPC Authors MEDIUM 4.9 * - - 20260916 20260916 NVD [버전범위 불명확] Arista EOS를 실행하는 영향을 받는 플랫폼에서 gNSI(gRPC 네트워크 보안 인터페이스) Authz Rotate RPC 문제로 인해 진행 중인 RPC 스트림에 업로드된 잘못된 인증 정책이 활성화될 수 있습니다. 이는 Bootz에 영향을 미치지 않습니다. 이 문제는 Arista 내부에서 발견되었으며 회사는 고객 네트워크에서 이 문제가 악의적으로 사용되는 것을 알지 못합니다.

This does not affect Bootz. This issue was discovered internally by Arista and the company is not aware of any malicious uses of this issue in customer networks.

영문 원문
[버전범위 불명확] On affected platforms running Arista EOS, when multiple gRPC Network Security Interface (gNSI) transports are configured, a race condition in the gNSI Authz service may cause a policy rotation to fail silently. An authenticated user whose access was revoked by the new policy may retain unauthorized access to gRPC interfaces. This does not affect Bootz. This issue was discovered internally by Arista, and the company is not aware of any malicious exploitation of this vulnerability in customer networks.

Attackers can craft a malicious model with arbitrary code in processing_llava_onevision2.py that executes with vLLM process authority even when trust_remote_code is set to False.
CVE-2026-90555 vLLM vllm MEDIUM 6.5 <0.28.0 0.28.0 - 20260912 20260916 NVD 0.28.0 이전의 vLLM 버전은 전사 끝점에서 오디오 샘플 속도 헤더의 유효성을 검사하지 못하므로 인증된 클라이언트가 기간 확인을 우회할 수 있습니다. 공격자는 샘플링 속도가 부풀려진 위조된 FLAC 헤더를 제출하여 과도한 메모리 할당을 유발하고 모든 테넌트에 영향을 미치는 API 서버 프로세스를 중단시킬 수 있습니다.

vLLM versions before 0.28.0 fail to validate audio sample rate headers in the transcription endpoint, allowing authenticated clients to bypass duration checks. Attackers can submit forged FLAC headers with inflated sample rates to trigger excessive memory allocation and crash the API server process affecting all tenants.
