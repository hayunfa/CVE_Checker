# 내부망 관리도구 테스트용 샘플

이 폴더의 파일은 **내부망 SW관리도구(프롬프트 #1)의 테스트 입력**으로 쓰라고 남겨 둔 견본입니다.
`output/` 과 달리 **매일 실행에 덮어써지지 않고, 90일 보관 정리 대상에서도 제외**됩니다.

| 파일 | 내용 |
|---|---|
| `CVE_20260814.xls` | **정본 (BIFF8)** — 실제 OSV+KEV 수집 데이터 300행 |
| `CVE_20260814.xlsx` | 같은 내용의 부가 파일 |
| `CVE_20260814.csv` | 같은 내용 (UTF-8 BOM) |

## 이 견본의 수집 조건

```
SCOPE lookback=150 sev>=MEDIUM groups=all sw=- in_use=True src=osv,kev scope=all max=300
```

- 감시대상 중 `in_use: true` 인 21종, 최근 150일, MEDIUM 이상
- 전체 724건 중 심각도·점수 상위 **300건**만 수록 (`TRUNCATED_CNT=424`)

## 규격 확인 결과

- 시트: `CVE_LIST`(301행 = 헤더 1 + 데이터 300), `META`
- 헤더 16개 순서·철자 규격 일치
- **전 셀 문자열** — TEXT 4,765개 + EMPTY 51개, 숫자·날짜형 **0개**
- `AFFECTED_RANGE` 에 공백 포함 건 0, `*`(범위 불명) 0건
- 심각도 분포: CRITICAL 49 / HIGH 251, KEV 등재 1건
